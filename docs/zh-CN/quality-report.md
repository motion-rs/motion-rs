## 测量方法

`examples/quality_metrics.rs` 以 JSON 格式输出 P6 质量报告；具体的测量逻辑位于 `examples/quality_metrics/metrics.rs` 中，`crates/motion/tests/quality_metrics.rs` 包含该模块，以便由同一套代码支撑非忽略的回归测试。所有测试均评估生产环境的 CPU 编译/准备/线性渲染路径，不进行性能计时。

- **细线渲染。** 包含 0.25px、0.5px 和 1px 宽度的垂直与水平线条，以 1/16px 步长移动（17 个不同位置）。遍历跨越线条的每个像素并与精确的解析覆盖率对比（`max_coverage_error`、`mean_coverage_error`）。将积分 Alpha 与解析面积对比（`energy_relative_error`），并在扫动区间内评估能量极差（`energy_relative_range`，用于度量闪烁），同时统计相邻帧的平均绝对 Alpha 差异。
- **文本渲染。** 采用内嵌 Noto Sans 字体的“Motion”字样沿相同步长移动：评估相对积分 Alpha 极差、超过 1 个覆盖码值的逐像素方向反转数（同时统计占扫动过程中发生变动像素的比例）以及单步最大的 Alpha 变动量。
- **渐变条带。** 一个 1024px 从纯黑到纯白的浮点渐变：统计不同的线性 f32 取值数量、单调性、最长相等连续值区间，以及朴素的 8-bit sRGB 量化表现（有效码值数量与最大码值阶跃）。输出阶段在此之上额外应用 Bayer 抖动。

这些是客观物理测量数据，而非主观感知评分。当两个轮廓相交时，文本像素值可能发生反转；单凭反转计数并不能证明存在光栅化缺陷。渲染器以 8-bit 精度存储解析路径覆盖率，而画刷和合成计算全程保持 f32。若无充分的数据依据，不得引入新的抗锯齿/覆盖率算法。

## 结果

在原生 macOS CPU 路径上通过以下命令测得：
`cargo run --locked --offline -p motion-rs --all-features --example quality_metrics`

| 线宽 | 最大覆盖率误差 | 平均覆盖率误差 | 能量与面积相对误差 | 能量极差（闪烁度） |
| --- | --- | --- | --- | --- |
| 0.25px | 0.00098 (0.25 码值) | 0.000082 | 0.39% | 3e-8 |
| 0.5px | 0.00196 (0.5 码值) | 0.000163 | 0.39% | 4e-8 |
| 1px | 0.00196 (0.5 码值) | 0.000154 | 0.39% | 0.39% |

覆盖率在水平和垂直两个方向上均精确在半个 8-bit 码值以内；残留的面积误差与 1px 细线的 0.39% 能量极差来源于独立的 8-bit 边缘覆盖率量化，极细线条的能量在整个扫动序列中几乎保持恒定。文本的积分 Alpha 波动仅为 0.05%；在扫动期间变动的 650 个像素中，仅有 48 个（7.4%）反转方向超过 1 个码值，且没有任何像素单步移动幅度超过 0.063（一个 1/16px 步长）。量化前的渐变在 **1024 个像素上呈现 1024 个互不相同且严格单调递增的 f32 数值**，无任何相等相邻像素；未经抖动的朴素 8-bit sRGB 量化即已覆盖全部 256 个色阶码值且最大步长仅为 1 个码值，证明在进入输出阶段前不存在任何中间画刷精度坍塌。

回归测试断言约束：覆盖率误差 <= 1.5 码值（平均 <= 0.75 码值），线能量误差与闪烁度 <= 1%，文本能量极差 <= 0.5%，文本反转比例 <= 12% 且单步 Alpha 变化 <= 0.1，浮点渐变严格单调且数值互异、包含 >= 250 个 8-bit 码值且步长 <= 4 码值。

测试数据表明无需盲目重构抗锯齿实现。保持现有的覆盖率策略，并在评估未来的亚像素/覆盖率提议时使用相同的固件进行度量。原生 CPU/GPU 光学/显示一致性与原生 Main10 精度/元数据测试同样顺利通过，涵盖基于 CPU 和 GPU 场景渲染的公开导出。本报告未执行任何性能基准测试或耗时比对。

## 验收情况

最终的全特性工作区功能验证（排除 `motion-bench`）通过了 767 项测试；按既有原生/慢速测试策略保留了 113 项忽略测试。所有 71 项公开 API doctest 全部通过。显式的原生电影级 GPU 一致性、原生 Main10 精度/元数据与公开 CPU/GPU Main10 导出检查均已通过。Breadth 轻量用例功能测试通过且未触发其计时路径。LUT 生成通过了四种风格、红通道快速单位映射、有限条目、无效输入防御和防覆盖检查。纯净静帧与胶片静帧通过示例生成并经人工视觉审查：[纯净版](../assets/cinematic-clean.png)、[胶片版](../assets/cinematic-film.png)。

完整的长片渲染配方曾暴露出一处准备保护带缺陷：同级快门采样曾被误计为串行滤镜。现在准备阶段会累加嵌套滤镜链并在同级快门采样中取最大值；64 个同级采样的回归测试已通过。

代码结构检查与生产环境 `expect` 清单检查均通过。涉及的 42 个 Rust 文件均通过格式化和声明间距检查。全库格式化脚本受 `.github/skills/motion-video/assets/main.rs` 中的既有格式差异阻止；该无关文件保持原样未作改动。
