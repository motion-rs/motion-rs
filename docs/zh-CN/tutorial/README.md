# motion-rs 教程指南

本教程按照创作工作流而非底层 crate 组织。从第一帧静帧开始，逐步学习动画、场景结构、多媒体内容、音频与导出，最后深入探索底层渲染与扩展机制。

示例均使用当前工作区的最新 API。Cargo package 名为 `motion-rs`；Rust 库名为 `motion`。
所有 Rust 示例均已标记为 `rust,no_run`。请根据各章节提示开启所需 Cargo 特性，并提供必要的外部测试文件。查阅文档本身不执行任何命令。

## 推荐阅读路径

- **初学者**：阅读 00，随后依次研读 01–05。第 02 章涵盖基础值类型，03 讲解随时间变化的动画，04 讲解场景与时间轴结构，05 介绍底层绘制接口。
- **制作短片**：学完基础路径后，根据内容需求选择 06–08，随后阅读 10–12。GPU 内部原理并非短片制作的前置要求。
- **集成至现有应用**：重点关注 09、11 与 12，了解输出格式、显卡设备与异步任务生命周期。
- **性能调优与代码贡献**：结合既有的设计契约深入研读 13 与 14。内部实现并不等同于稳定的公开创作 API。

## 示例约定规范

1. 每章均阐明其学习目标、所需 Cargo 特性、最小可运行程序、核心 API 汇总表格、避坑指南与进阶阅读。
2. 除特别说明外，默认均使用 CPU 后端。启用 `gpu` 特性仅增加编译支持，并不强制选中该后端。
3. 相对文件路径一律相对于程序的当前工作目录。请显式配置资源根路径与字体环境。
4. 默认情况下，示例不会盲目覆盖已存在的文件，不会自动弹窗，也不运行耗时的性能测试。
5. 简短的创作代码使用 `motion::prelude::*`。底层协议使用 `motion::extend`，显式渲染契约使用 `motion::render`，编码器使用 `motion::encode`，预编译内容使用 `motion::eager`。

[设计契约](../../zh-CN/design/README.md)系统阐述了架构、渲染与所有权规范；[开发指南](../development.md)阐述了完整的验证流程。这些参考文档并非学习本教程的前置条件。
